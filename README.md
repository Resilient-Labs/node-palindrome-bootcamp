# Project: Server Side Palindrome Checker 🏎️

### Goal: Create a simple web application that uses the fs and http modules to validate if a string is a palindrome server-side.

## Tech Stack

- **Front end:** HTML, CSS, JavaScript (Fetch API)
- **Back end:** Node.js (`http`, `fs`, `url`, and `querystring` modules)
- **Hosting:** GitHub Pages

## How to Use:

* User inputs words and clicks submit
* A message will display showing if the word is a palindrome or not. 

## Run Locally

**Requirements:** Node.js

1. Clone the repository and move into it.

   ```bash
   git clone https://github.com/programmingKat/node-palindrome.git
   cd node-palindrome
   ```

2. Install dependencies.

   ```bash
   npm install
   ```

3. No `.env` file is needed. The server runs on port 8000.

4. Start the server.

   ```bash
   node server.js
   ```

5. Open `http://localhost:8000` in your browser.
