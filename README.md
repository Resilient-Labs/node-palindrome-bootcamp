## Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/PalindromeChecker.git
````

2. Navigate to the project directory:

```bash
cd PalindromeChecker
```

3. Open Project File

4. Use in browser
   
## Usage

1. Enter your word into the input.
2. Click the button to check whether the word is a palindrome.
